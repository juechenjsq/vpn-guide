连接排查

绝尘加速器连接不上、状态 -1、连接后没网怎么排查

从节点、模式、本地网络到系统网络栈依次排查。Windows 11 24H2、虚拟网卡和手机网络刷新分别处理。

最后更新：2026 年 10 月 5 日

先按症状走：连接后完全没网、状态显示 -1、Windows 11 24H2、只有某个应用异常，处理方法并不一样。

连接后无网络：先做 4 个基础测试

  1. 换一个地区或节点重新连接，排除当前节点临时波动。
  2. 如果正在用【智能模式】，临时切到【全局模式】测试是否为分流问题。
  3. 更换本地网络：Wi‑Fi 与移动网络互换；电脑端可换 Wi‑Fi、网线或其他网络。
  4. 完全退出绝尘客户端，再重新打开和连接。

如果绝尘可以连接，但只有 Telegram、TikTok 或其他单个应用加载异常，更适合直接查看 速度与应用排查。

连接状态显示 -1 / 一直无法建立连接

设备处理方法
WindowsWin+R → 输入 cmd → 执行 ipconfig /flushdns。仍异常时检查当前实际联网网卡的 DNS，不要改绝尘虚拟网卡。
Android开启飞行模式 10–15 秒再关闭；重新开关或重连 Wi‑Fi；必要时重启手机。若只某个 App 异常，可强制停止后重开。
iPhone / iPad开启飞行模式至少 15 秒 → 关闭 → 重连 Wi‑Fi / 移动网络 → 再连接绝尘。仍异常可忽略当前 Wi‑Fi 后重新加入，或重启设备。
Mac在 Terminal 执行 sudo dscacheutil -flushcache，再执行 sudo killall -HUP mDNSResponder。输入登录密码后通常不会显示“刷新成功”。
Windows DNS：官方帮助建议可保留一个国内 DNS，并添加 8.8.8.8 作为备用。修改时针对当前实际联网的本机网卡，而不是绝尘虚拟网卡。已有自定义 DNS 时可在“高级”中继续添加。

Windows 11 24H2 连接后无法上网

  1. 打开 Windows【设置】。
  2. 进入【系统】→【可选功能】。
  3. 向下找到并打开【更多 Windows 功能】。
  4. 勾选【Virtual Machine Platform（虚拟机平台）】。
  5. 确认安装完成后重启电脑，再打开绝尘测试。

虚拟网卡是什么？手机为什么没有

虚拟网卡是电脑端用于接管和转发网络流量的 VPN 虚拟网络驱动。Android / iOS 等移动端没有这个开关属于正常情况。

正常情况下可优先保持虚拟网卡开启；如果出现无法连接、连接后没网或特殊网络兼容问题，可尝试关闭虚拟网卡，切换为系统本地驱动后重新连接测试。

全局模式和智能模式

模式适合场景
全局模式所有访问流量都通过绝尘线路。适合排查智能分流导致的个别应用异常，或需要所有应用统一走节点时。
智能模式按访问目标自动分流，国内服务优先本地网络，海外或指定平台通过绝尘线路。当前客户端标记为 VIP 功能。

什么时候该联系人工客服

如果以上步骤都没有恢复，准备这 4 项信息：当前网络类型、所选节点、客户端版本号、故障截图。客服入口可从客户端首页左上角耳机图标进入，也可从【我的】→【联系客服】进入；人工客服全年每日 09:00–23:59 提供服务。
